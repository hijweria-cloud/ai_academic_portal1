# AI-Based LMS and Academic Assistance Web Portal 🎓🤖
> **Affiliated with Government College University Faisalabad (GCUF)** > Developed as a Final Year Project (FYP) to bridge the gaps in traditional Learning Management Systems.

---

## 📝 Project Overview
The **AI-Based LMS and Academic Assistance Web Portal** represents a paradigm shift from conventional, passive web-based educational platforms into active, data-driven learning spaces. While traditional portals only display quantitative scores, this platform introduces real-time qualitative analysis, AI-guided mentorship, and proactive grade forecasting.

### 🌟 Core Innovations
1. **Interactive AI Assistant (Gemini API):** An embedded asynchronous chatbot framework utilizing conversational generative AI to provide 24/7 academic configuration help, policy queries, and guidance.
2. **Predictive Grade Engine (Decision Tree Regressor):** Trained using internal academic evaluation frameworks (Mid-Term metrics, Assignments, Presentations) to forecast final GPAs early in the semester, highlighting at-risk students.
3. **Advanced Administrative Control Panel:** Secure management streams using a golden-dark luxury interface to handle programs, dynamic database mapping, and dynamic synchronization with student performance charts.

---

## 🛠️ System Architecture & Technologies
The application splits heavy computational analytics from native web pipelines via a dual-layered execution approach:

* **Frontend User Interface:** HTML5, CSS3 (Bootstrap 5.3.3), Custom 'Poppins' Typography, Asynchronous jQuery/AJAX token channels.
* **Web Core Engine (Native Portal):** PHP (with structural procedural/OOP database interactions and custom `.cls` document compiler configurations).
* **Database Management:** MySQL (Relational models mapping records for `students`, `programs`, and `marks`).
* **AI Analytics Service (Backend API):** Python (Flask-powered dynamic Microservices hosted locally on port `5000` to execute runtime modules without web blocking).
